# HTTP API

Prefix `/api`, except `POST /webhooks/razorpay`.

Machine-readable spec: `/api/openapi.json`. Human UI: `/api/docs`. Try It uses the API process from `HONO_APP_URL` and sends the documented JSON body and query params.

| Method | Path                         | Role                                      |
| ------ | ---------------------------- | ----------------------------------------- |
| GET    | `/api/clusters`              | Queue                                     |
| GET    | `/api/clusters/:id`          | Graph, evidence, audit                    |
| POST   | `/api/clusters/detect`       | Run detector                              |
| POST   | `/api/clusters/:id/decision` | Freeze / block / escalate / dismiss       |
| GET    | `/api/holds`                 | Authorized, not captured                  |
| POST   | `/api/holds/:id/release`     | Capture (only capture in this system)     |
| POST   | `/api/holds/:id/reject`      | Refund                                    |
| POST   | `/api/ingest/demo`           | Load synthetic data                       |
| GET    | `/api/metrics`               | Offline eval + live funnel                |
| GET    | `/api/evidence`              | Full measurement pack, including failures |
| POST   | `/api/voice/speak`           | TTS. Does not move money                  |
| POST   | `/api/voice/listen`          | STT + rule parse                          |

Dismiss and hold-reject require a reason. Full table: `docs/api.md` in the repo.
