# Introduction

AI Risk Manager finds groups of accounts that share fraud-specific signals. It does not score a single Razorpay payment in isolation. That is Thirdwatch's job.

The pipeline is: ingest accounts and transactions, build a labeled graph, cluster with Louvain, score corroboration, stop. A merchant then freezes a cluster or releases a payment hold. Voice (English, Hindi, Marathi) can ask; it cannot capture or cancel.

All evaluation data in this repository is synthetic. Numbers on `/metrics` and `/evidence` are files produced by scripts under `services/`, plus live Postgres counts, kept in separate fields.
